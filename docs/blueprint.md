# **App Name**: CruiseMailer

## Core Features:

- Input Form: Form with fields for Customer Name, Ship Name, Cruise Date, Nights, Cruise Name, Adults, Children, Drinks Package, Experience Type, Cabin Type, Decks, MSCBook Price, %Discount, Deposit, and Due Date.
- Live Email Preview: Dynamically generate a preview of the email based on the input form fields. The AI tool should incorporate appropriate data points based on detected content type.
- Copy to Clipboard: A button to copy the generated email content to the clipboard for easy pasting.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to evoke a sense of trust and professionalism.
- Background color: Light gray (#F5F5F5) to ensure readability and a clean aesthetic.
- Accent color: Darker blue (#1976D2) for key actions like the 'Copy to Clipboard' button.
- Font: 'Inter' (sans-serif) for both headlines and body text, providing a modern and clean look.
- Clean and organized layout with clear sections for the input form and email preview.
- Subtle animation on button click to confirm the email is copied.
